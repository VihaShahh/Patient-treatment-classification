# Message and review examples

Each file contains 128 authored examples built from 16 templates and 8 topics.
`spam.csv` has spam/ham labels; `sentiment.csv` has positive/negative labels.
The examples retain their CC0-1.0 dedication.

Train and test rows share templates and vocabulary, so accuracy on these files
does not describe performance on real messages. Neutral sentiment, sarcasm and
other languages are outside these exercises.
