# Notebook guide

Start with `patient_basics.ipynb` or `iris.ipynb`. Each notebook runs independently.
Wine covers scaling; digits shows image features; breast cancer examines class
errors. Churn and equipment mix numeric and categorical columns. Transactions
has an imbalanced label. Spam and sentiment introduce text vectors.

Open a notebook and run its cells in order. Sources are in the
[dataset notes](../datasets/README.md).
