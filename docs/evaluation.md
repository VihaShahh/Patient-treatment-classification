# Reading the scores

Training and test rows are separate, using a fixed seed and stratified labels.
Fit preprocessing on training rows only. Accuracy counts correct predictions;
precision and recall help explain mistakes for an individual class. The
majority-class model gives a simple comparison.

Repeatedly choosing a model from the same test scores makes them optimistic.
These scores describe these exercises, not performance on new real-world data.
Patient examples do not validate treatment decisions. Feature importance is
not a causal explanation. See the [dataset notes](../datasets/README.md) for sources.
